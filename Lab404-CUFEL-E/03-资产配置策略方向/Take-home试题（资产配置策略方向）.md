> **笔试时间：**2026 年 10 月 11 日16：00-22：00，限时 6 小时。

## 1. 项目背景

你接手了一项尚未完成独立复核的量化研究。前任分析师使用一组匿名因子建立了截面收益预测原型，留下了研究报告、数据处理与建模代码、预测结果及简化回测。报告中的部分指标较为突出，团队正在讨论是否继续投入研究资源。

现有资料足以让你重建研究过程，也留下了不少尚待确认的问题。你需要代表新接手的研究员，给出一份能够经受复核的研究判断。

**核心问题：这项研究目前有哪些结论值得相信？团队接下来应该做什么？**

你的结论可以支持继续研究、提出有条件的下一步实验，也可以建议暂停。请根据实际证据作出判断，并说明仍有哪些不确定性。

## 2. 交付目标

请围绕交接项目完成一项可运行的研究工作。你可以复核原有结论、重建关键实验、改进一部分研究流程，或沿着自己发现的关键问题开展进一步研究。

研究范围由你确定。我们希望看到以下内容：

1. **能够实际运行的研究过程。** 使用随题提供的数据，产生可复核的真实计算结果。允许复用交接代码，也允许调整或重写；请明确你采用了哪些内容。
2. **对至少一项关键研究结论给出判断。** 说明选取该结论的原因、核验方法、计算结果，以及证据支持到什么程度。
3. **开展至少一项由你决定的后续验证或研究。** 可采用新的实验、另一种验证口径、某项改进方案，或针对原研究薄弱环节进行进一步核查。选择本身需要有理由。
4. **交付能够追踪的证据。** 重要数值与图表应能对应到输入数据、计算逻辑、运行命令及产出的文件；实际无法验证的部分请如实说明。
5. **给出明确的下一步建议。** 说明现在可以下什么结论、哪些结论还不成立，以及如果继续投入，你会优先开展什么工作。

这项任务没有预设的收益目标，也没有要求所有候选人训练新模型。研究的完整性、可靠性和取舍，将通过提交项目进行复核。

原始研究报告及代码属于交接资料。其研究方法和结果尚待你独立核验。

## 4. 研究边界

- 研究对象限于题目提供的匿名合成资产；可以查阅公开资料和技术文档。若额外使用其他数据或代码，请清楚标注来源、用途及其对结论的影响。
- 可自行选择 Python 库、模型、实验管理方式及结果展示形式。一般 CPU 环境即可完成核心研究。
- 请自行控制工作量。完整重建商业级研究平台、覆盖所有因子、优化全部参数和制作可视化前端均不在交付要求之内。
- 对于暂时无法解决的问题，可以提出可执行的后续验证方案，并清楚区分已完成的实验与计划中的工作。

**本任务不以功能数量、模型规模或收益指标的高低作为主要评价依据。** 请把时间投入你认为最有价值的研究环节。

## 6. 提交要求

请提交一个项目目录或指定仓库，包含以下四项：

| 必须提交                         | 最低内容                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------ |
| 可运行代码                       | 完成你所选研究范围所需的源码及依赖说明；交接代码若有修改，请保留或说明修改位置 |
| `README.md`                    | 环境与运行命令、项目主要流程、输入输出位置、已完成范围、关键限制               |
| `research_report.md`（或 PDF） | 关键研究结论、验证依据、后续研究及团队下一步建议；图表可以附在其他文件中       |
| `outputs/`（或同等目录）       | 至少一次实际运行产生的关键结果，并能对应到报告中的核心判断                     |

报告篇幅建议控制在 **3–6 页等效篇幅**，以信息充分、论证清楚为准。代码可以依赖随题数据包，无需重复上传大体积的原始数据；须注明数据包版本及预期目录位置。

提交前，请按 `README.md` 在新终端运行一次核心命令。请勿提交密钥、访问令牌、无关缓存或大型模型文件。
