# 原始研究报告（交接件）｜跨截面多因子预测原型

> 文件属性：前任分析师的初步研究稿；**未经过独立复核，不构成准确性背书。**
> 数据范围：匿名合成日度资产，2021-01-04 至 2024-12-31。

## 1. 研究目标与项目状态

希望验证匿名因子池能否对下一期截面收益形成稳定预测，并讨论是否有条件进入下一阶段模拟研究。现有数据共包含 20 个供应商研究因子、日行情、风险代理和交易条件。先基于全部因子训练一个快速非线性原型，再用高分组与低分组的未来持有期收益差观察信号潜力。

这份文档仅包含原流程的交接结论及已保存的产物。请审阅者自行查验代码、数据和推断链路。

## 2. 原流程摘要

1. 以 `date + asset_id` 关联行情、因子快照与候选股票池。
2. 以 `open(t+6)/open(t+1)-1` 作为原型目标。
3. 从全量有标签记录随机抽取 110,000 条，再进行随机 80/20 行级划分（训练 88,000、验证 22,000）。
4. 训练 `HistGradientBoostingRegressor`（20 列因子），预测所有可计算标签的日期资产行。
5. 按各日预测排名，比较预测最高/最低十分位未来五日开盘到开盘收益；当前指标未扣交易成本。

## 3. 保存的观测结果（来自附带代码的真实执行）

| 指标 | 原流程保存值 |
|---|---:|
| 随机留出样本 Pearson 相关 | 0.3372 |
| 随机留出样本 RMSE | 0.0448 |
| 全样本最高/最低十分位平均未来五日收益差 | 5.62% |
| 全样本重叠持有期收益差年化代理 Sharpe | 99.77 |
| 产生分组收益序列的日期数 | 1036 |

注意：以上均为原流程定义的数值，没有独立验证过其是否可作为真实投资绩效指标。尤其表中“重叠持有期收益差年化代理 Sharpe”不是已成交策略的实际净值夏普比率。

原流程另保存了逐因子扫描表。根据其全样本未经时点核验的日度平均 RankIC，数值靠前的字段包括：factor_03: 0.396, factor_02: 0.075, factor_08: 0.073, factor_17: 0.069。这些初步结果尚不能解释预测能力来源。

## 4. 前任初步结论

原型在交接版本中显示出较强的预测相关性，因子池可能值得进入后续研究。但当前回测尚未包含完整执行约束、交易成本及独立时序样本；对供应商因子、验证过程和预测成果的独立复核尚未完成，因此不能直接据此做投产决策。
