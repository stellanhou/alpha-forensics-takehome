# Alpha Forensics 候选人数据包 v1.0

- 数据性质：400 个匿名**合成**资产、20 个匿名合成因子。
- 公开日期：2021-01-04 到 2024-12-31（共 1042 个合成交易工作日）。
- 所有 `.csv.gz` 是普通 UTF-8 CSV 的 gzip 压缩版本，pandas 原生支持；有条件可自行转 Parquet，但**无需安装 pyarrow 即可完成题目**。
- `baseline` 文件为待复核历史项目交接产物，附源码、实际运行结果和研究摘要。
- 基础环境：Python 3.10+，numpy、pandas、scikit-learn，普通 CPU 足够完成原始交接版本复现。
- 本包不包含出题方数据生成器、隐藏期、因子真实机理、参考结论或内部评分工具。

使用前请先阅读 `README_数据包.md` 及 `data/data_dictionary.md`。
